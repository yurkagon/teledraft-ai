```text
Primary request: a distinctive, polished minimal geometric emblem combining a folded draft/document with a paper-plane motion and one small four-point AI sparkle.
Style: crisp flat vector-like shapes, modern professional software brand, legible at 128 pixels.
Composition: a single compact centered emblem with generous transparent margin.
Color palette: main Telegram-inspired blue #087abb, pale blue #d4e8f5, a small dark ink #172b3a accent if needed.
Constraints: genuinely transparent background, no text or letters, no gradients, no shadows, no 3D, no watermark; own original brand mark rather than the official Telegram logo.
```
